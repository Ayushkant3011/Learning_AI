# Learning_AI



#### Steps to create a new project and run it in venv
- to create a new folder -  uv init day2 
- cd day2
- create the virtual environment - uv venv --python 3.14
- activate the venv - .\venv\Scripts\activate.ps1
- to create the python file - code sys_temp.py
- to run -  python .\sys_temp.py
- to deactivate the venv - deactivate 


#### if you want to add any dependencies in venv:
- move to the day 2 folder
- pip install the dependencies
- uv add <dependency_name> #ex: uv add python-dotenv
